# 🍽️ Diet Monitoring System

## 🔥 Overview
This project is a **Food Classification and Volume Estimation System** using **ResNet-18** for feature extraction and **KNN** for classification. It estimates the food **volume using extracted features** and calculates **calories accordingly**.

## 🏗️ Project Structure
DietMonitoringSystem/
├── backend/
│   ├── app.py            # Flask API
│   ├── uploads/         # Stores uploaded images           
├── dataset/
├── frontend/
│   ├── index.html        # Web UI
├──models/
